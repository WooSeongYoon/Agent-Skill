# 분야별 검증 표

| 변경 | 최소 유효 검증 | 별도로 남길 한계 |
|---|---|---|
| Python 로직 | 계약/회귀 테스트, 필요한 린트·타입 검사 | 실제 외부 서비스 |
| Qt | signal, 취소, 종료, 응답성 | OS 화면·패키징·GPU |
| Docker | Compose 검사, 빌드, 임시 컨테이너 smoke | 배포 환경·장치 |
| 웹 | 기존 테스트/빌드, 변경한 브라우저 흐름 | 미실행 브라우저·실서비스 |
| ML | 데이터 경계, 작은 배치, 추론/복원 | 전체 학습·품질·CUDA |
| 스킬 | 구조/참조 검사, 대표 요청 적용 | 모든 모델·호스트의 행동 |

보고 예시: 변경 이유 → 주요 파일 → 실행한 명령/결과 → 미검증 항목. 실행하지 않은 명령을 실행 목록에 넣지 않는다. 실패한 검증을 숨기거나 테스트 자체를 삭제해 통과시키지 않는다.
