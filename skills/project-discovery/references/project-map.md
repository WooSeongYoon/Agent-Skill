# 프로젝트 지도

| 확인 대상 | 우선 근거 | 주의점 |
|---|---|---|
| Python | pyproject.toml, CI, 잠금 파일 | 설치 도구의 Python 버전과 앱의 지원 버전을 구분한다. |
| Qt | import, 의존성, .ui/.qml | PySide/PyQt를 혼합하지 않고 Widgets/QML 경계를 확인한다. |
| 웹 | package.json, lockfile, 서버 진입점 | 기존 프레임워크와 패키지 관리자를 따른다. |
| ML | 모델 코드, 학습 설정, 데이터 분할 | 예제 텐서 검사와 실제 데이터 평가를 구분한다. |
| Docker | Dockerfile, Compose, CI | 이미지 빌드, 서비스 실행, 배포는 다른 작업이다. |

Qt + ML 프로젝트는 UI → 작업 요청 → 추론 서비스 → 결과/오류 신호로 경계를 그린다. 모델 코어가 GUI 객체를 참조하지 않게 한다. 요청된 문제에 필요한 경계만 수정한다.

명령 기록 예시: `"test": ["python", "-m", "pytest", "-q"]`. 프로젝트에 pytest가 설정되어 있다고 확인한 경우에만 쓴다. 별도 작업 디렉터리와 서비스 조건은 notes에 기록한다. 설치기는 이 명령을 실행하지 않는다.
